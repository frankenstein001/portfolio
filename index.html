Background

I build web platforms end to end, from interface implementation through to the infrastructure they are deployed on. Most of my work is client-facing agency and product sites, where the brief arrives as a design file and the requirement is a fast, accessible, maintainable build.

Alongside that I run my own server and network environment — containerised services, segmented VLANs, local DNS, and automated workflows. It is where I test deployments and failure scenarios before they reach anything a client depends on.
